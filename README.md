# stroke-timelapse-capture
Lightweight Python tool that captures sequential screenshots automatically with pause/resume and smart naming. Friendly to illustrators who need clean timelapse frames of their workflow, especially suitable for long drawing sessions thanks to small file sizes (~60–70 KB per image).
Tested use case environments include:
- Wacom Mobile Studio Pro 13 Gen 1 by :contentReference[oaicite:0]{index=0}
- RETAS Studio animation workflow
